# ChampMan 01/02 Remake — Obsidian Vault

Shared documentation vault for the ChampMan 01/02 Remake project.

## Structure

| Folder | Purpose |
|--------|---------|
| `roadmap/` | Current work, backlog, known issues |
| `architecture/` | High-level design docs (match engine, multiplayer, .dat parser) |
| `data-model/` | Entity definitions (Player, Club, Competition, Tactics) |
| `decisions/` | Architecture Decision Records (ADRs) — dated, numbered |
| `research/` | Notes from reverse-engineering, community tools, match engine analysis |
| `reviews/` | Plan reviews, spike results |

## Conventions

- ADRs: `NNNN-kebab-title.md`, numbered sequentially, dated
- Research notes: link sources, note dates
- Current work: updated by whoever is actively working
- Decisions are **settled** — once an ADR is written, changes require a new ADR that supersedes it
